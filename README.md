How to publish on GitHub Pages

This repository is intended to be used as a GitHub Pages site. For a user site (https://blackkandy.github.io) the repository must be named `BlackKandy.github.io` and the site will be served from the default branch root automatically.

If you need to change the branch that serves Pages, open the repository Settings → Pages and choose the branch and folder (root or /docs).
